# juxtaposed (R) 0.4.0

**22 November 2026 · regional expression.** Use `regional_juxtaposition_matrix(X, graph)` to measure whether two genes occupy similar tissue neighborhoods. Positive values capture shared high or low signal. Use the original `juxtaposition_matrix` for opposing changes across edges. The regional score has descriptive output on [−1, 1] with equally weighted heat steps 1, 2, 4, 8 and 16.


R implementation of the juxtaposition index J with calibrated all-pairs inference. It gives the
same results as the Python package `juxtaposed` 0.4 to numerical precision; the tests compare
against fixtures generated by the Python package.

```r
# install.packages(c("Matrix", "RANN"))
# R CMD INSTALL juxtaposed
library(juxtaposed)
g   <- visium_graph(array_row, array_col)            # or spatial_graph(coords, neighbors = 6)
tab <- juxtaposition(expr, g)                        # J, spectral z, p, BH q for all pairs
nl  <- spectral_null(g)                              # reuse for several gene sets
spectral_test_lee(nl, expr)$p                        # calibrated p-values for Lee's L as well
e   <- score_edges(expr[, c("EPCAM", "MGP")], g, scale = 4, ridge = 1, smoother = "lazy")
spot_map <- edges_to_nodes(e, nrow(expr))            # local J per spot, for plotting
```

Features introduced in 0.3 include
- `power` (power-mean denominator; `power = 0` is negative codispersion);
- `laplacian = "normalized"`;
- the lazy-walk local maps;
- `edges_to_nodes()`.

The GPU backend is Python-only.

On 22 November 2026, the local release candidate passed its package tests and R CMD check with the manual build disabled. Regional scores agreed with Python on full marker matrices from DLPFC, seqFISH and Allen MERFISH.
